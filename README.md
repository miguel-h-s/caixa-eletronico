# 🏧 Caixa Eletrônico em Go

Projeto em **Go** criado com fins educacionais para praticar lógica de programação, entrada de dados, condicionais e estruturas de repetição.

O programa simula um **caixa eletrônico simples**, executado no terminal.



## 📌 Objetivo do projeto

- Praticar conceitos fundamentais da linguagem Go
- Evoluir o mesmo projeto em versões
- Aprender Git e GitHub na prática
- Evitar apenas copiar código, focando em raciocínio lógico



## 🧩 Versões do projeto

### 🔹 Versão 1 (v1)
📁 Código-fonte inicial

Funcionalidades:
- Leitura do nome completo do usuário
- Entrada de saldo atual
- Entrada de valor de saque
- Validação de valores inválidos
- Cálculo do saldo restante
- Encerramento do programa após uma operação

Tecnologias/conceitos usados:
- `fmt`
- `bufio.Reader`
- `strings.TrimSpace`
- Variáveis
- Condicionais (`if / else`)



### 🔹 Versão 2 (v2)
📁 Evolução da v1 com loop e funcoes

Novidades:
- Uso de `for` para repetir operações
- Possibilidade de realizar vários saques
- Comando `/exit` para sair do programa
- Código mais organizado
- Primeira função criada pelo autor

Tecnologias/conceitos adicionados:
- Estrutura de repetição `for`
- Funções
- Variável global (para estudo)
